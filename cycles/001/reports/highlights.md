# Research highlights and anomalies

Status: exploration; all scientific interpretation is exploratory. No local model was trained or scored during this phase. Details, predictions and the decision rationale are in [research.md](research.md); source IDs resolve in [sources.json](../research/sources.json).

- **Keep the question narrow.** Both primary arms use AdamW. The intervention is the registered decay coefficient, including biases; this does not compare AdamW against Adam or an L2 penalty. Sources: src-adamw-paper, src-torch-adamw; local audit: audit-fixture-source.
- **Prior exposure is explicit.** The closest supplied-fixture executions already exist. Their outcomes cannot establish new confirmation here. The prior disclosures also separate agent work from controller repairs. Sources: src-prior-haiku, src-prior-luna, src-haiku-disclosure, src-luna-disclosure.
- **Pilot wording needs care.** Reload verification forwards all images; pilot scoring uses validation labels. Do not claim that test inputs are never accessed. Source-level inspection found no test-label fitting or selection path; dynamic checks remain pending. Evidence: audit-fixture-source; source: src-haiku-disclosure.
- **Small interventions can tie on accuracy.** Identical correctness vectors would force a zero-width example-bootstrap interval even if parameters or confidence differ. This is a prediction from the registered statistic, not an observation or an equivalence claim. Method source: src-bootstrap; definition: research/protocol.json.
- **Baseline semantics matter.** Logistic regression is regularized; the class-prior control is a constant majority-class prediction, not random class sampling. Useful shuffled-label accuracy would trigger investigation, while a failed shuffled control would not certify all leakage absent. Source: src-logistic; evidence: audit-fixture-source.
- **Dataset scope is limited.** A random example split within the loader's UCI subset does not preserve the original writer-held-out design. Sources: src-digits-loader, src-uci-digits, src-splits.
- **Provenance can fail after successful execution.** The Luna disclosure documents line-ending and regeneration hash failures. Preserve original bytes and verify publication; do not treat regenerated files as immutable evidence. Source: src-luna-disclosure.
- **Moving documentation changed target.** The stable PyTorch optimizer link redirected to a newer release family. The review used versioned docs matching the pinned family; installed behavior is still to be checked. Sources: src-torch-adamw, src-reproducibility.

Expected next learning: first establish that artifacts and data boundaries behave as inspected, then compare paired saved predictions. Retain seed disagreements and negative controls, and distinguish conditional precision from generalization. Keep hypotheses and observations separate, following src-nanda-process and src-lones-pitfalls. No scientific effect has been verified, falsified or estimated locally yet.
