## Predictions and competing explanations

- Existing result and checkpoint bytes should still match the accepted experiment audit and frozen source/protocol. Drift, a stale checkpoint or split misalignment would instead invalidate the affected interpretation and require investigation before handoff.
- Recomputing the registered paired statistic should reproduce the saved aggregate. Identical per-example correctness should force its degenerate zero interval; a disagreement would favor an implementation or aggregation bug over a scientific explanation.
- Primary paired states should remain different despite correctness ties. This addresses accidental identical-checkpoint reuse only; it does not distinguish confidence changes, local decision-boundary changes or behavior outside the scored examples.
- Every real-label neural arm and the logistic baseline should remain above each negative-control result; logistic should remain descriptively below each real-label neural result. Failure would require correcting the prose, not discarding a result or refitting a model.
- The weaker decay arm should retain the observed per-seed accuracy ties. This does not predict equal probabilities, universal equivalence or optimal coefficients.
- All final claim references should resolve to source, experiment or registered local-audit IDs, and all requirement evidence paths should exist. Broken references are presentation defects to repair using preserved measurements.
